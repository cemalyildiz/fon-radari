# Fon Radarı

Ulusal ve uluslararası proje çağrılarını tarih, destek türü, başvuru koşulları ve resmî kaynak bağlantılarıyla sunan web sitesi.

## Yerel geliştirme

```bash
npm install
npm run dev
```

## Yayınlama

`main` dalına yapılan her gönderim GitHub Actions ile statik siteyi oluşturur ve GitHub Pages’e yayımlar. Avrupa Komisyonu çağrı verileri saatlik iş akışıyla yenilenir.
